# emp-hte-audit

Analysis pipeline and calibrated simulator for:

> **Measurability Limits and Scale-Dependent Metric Transfer in Heterogeneous
> Treatment Effect Estimation: A National-Scale Audit of Employment-Insurance
> Records** (submitted to IEEE Transactions on Big Data)
>
> An earlier version, *When Does Heterogeneous Treatment Effect Estimation Pay
> Off?*, was accepted at IEEE BigData 2026 (regular track) and withdrawn before
> publication; this repository covers both.

Every number in every table and figure of the paper is generated by this pipeline —
nothing is transcribed by hand. Tables are exported to `paper/tab/*.csv` and figures to
`paper/fig/*.pdf` at the end of a run.

## What can be reproduced without the administrative data

The national employment-insurance records cannot be redistributed. The repository
therefore supports two reproduction levels:

| Level | Needs | Reproduces |
|---|---|---|
| **Full-synthetic** (anyone) | this repo only | the calibrated simulator (Sec. III), oracle-constant test on the simulator (Table II, lower block), three-layer learnability (Table III), PEHE decomposition and Ω (Table IV), shrinkage/α\* verification (Sec. VI, Fig. 2), confounding and hidden-confounding sweep (Sec. VII), ablations (Table V), IHDP/Jobs results (public benchmarks) |
| **Full** (with data access) | approved access to the employment-insurance extracts | additionally: real-cohort ranking/power/cost/policy value (Sec. IX), national-scale validation (Sec. X, Table VII) |

## Layout

```
cdtlib/            library: data IO, standardization, estimators, scoring, config
  models.py        6 estimators (naive, S-, T-learner, causal forest, TARNet, CDT)
                   + tie-neutral Qini/AUUC, PEHE decomposition
  dataio.py        standardization to per-person (state, action, outcome) tensors
  outcomes.py      index-month construction, Y1/Y2/Y3 at horizons {6,12,24}
tools/
  gen_empservicesynt.py   calibrated simulator (CRN counterfactuals, hidden-confounding
                          parameter, R-replicate ground truth)
  verify_benchmarks.py    IHDP/Jobs canonical-release checks
  verify_synt_v2.py       11 simulator self-checks (V1–V11, C8)
icml_run110.ipynb  THE pipeline: run top-to-bottom → every table and figure in the
                   paper, including the national-scale experiment, its 3-seed
                   re-verdicts, and the subsample-draw stability check
```

## Journal extension (`sci_run117_git.ipynb`, reference outputs in `out_ref117/`)

The journal submission adds five experiment families beyond the conference
pipeline. They live in `sci_run117_git.ipynb` (cache-backed cohort loading with a
single explicit build cell), and the reference outputs behind every new table
and figure are committed under `out_ref117/` — generated by the notebook,
nothing transcribed by hand:

* `117A` information-set ladder (instrument validation: the measured ceiling
  climbs 0.06 → 0.73 as the generator's information is revealed stepwise)
* `117B` seven-learner and sample-size triangulation of the history ceiling
* `117D`/`117F` fourteen-candidate selection transfer at two scales
  (16,000 / 240,000), with 20,000-draw permutation p and leave-one-out ranges
* `117C` event-study cross-check (Ashenfelter dip) at both scales
* `117E` horizon sweep h ∈ {6, 12, 24}

The conference pipeline is unchanged in
`icml_run110_ieeebigdatasubmit.ipynb` (named `icml_run110.ipynb` below).

## Requirements

Python ≥ 3.12; `torch` (CUDA build matching your GPU; RTX 50-series needs cu128 wheels),
`econml` ≥ 0.17 (**hard-gated at startup** — without it the "causal forest" silently
degenerates to a T-learner, which is one of the failure modes the paper documents),
`xgboost`, `scikit-learn`, `pandas`, `numpy`, `pyarrow`, `matplotlib`, `psutil`.

## Running

Open `icml_run110.ipynb` in the repository root and run all cells. On one consumer GPU
(RTX 5070) the complete pipeline — 2,070 training runs plus the national-scale
experiment — takes ~2.7 h (9,573 s in our logged run). Every section prints a
timestamped progress line; the final cell writes `out/00_결과요약.txt`, a one-file summary
whose lines correspond to the paper's claims.

Reproducibility guards you will notice: the notebook refuses to run if the library hash
does not match, if `econml` is missing, or if the models file lacks the tie-handling
patches; cohort construction is content-addressed; strict deterministic kernels are
enabled when the hardware supports them and the probe result is recorded in run
metadata.

Optional completion notifications use environment variables `TG_TOKEN` / `TG_CHAT`
(never hard-coded).

## Data availability

Raw administrative extracts: not distributable (national employment-insurance records).
The simulator in `tools/gen_empservicesynt.py` is calibrated to the published marginals
(employment rate 0.3264, E[log wage | employed] 5.4742, take-up 0.492) and regenerates
the synthetic cohort exactly from a fixed seed, with all parameters recorded in
`meta.json`.
